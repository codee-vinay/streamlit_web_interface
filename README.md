💻 DevStudio – Python Development Workspace
📌 Project Overview
DevStudio is a frontend-based Python development workspace built using Streamlit. It provides a simple, interactive and user-friendly interface for exploring Python programming concepts and organizing coding experiments.

The application is designed with a sidebar navigation system, multiple workspace pages, interactive input components and dedicated output sections.

The current version focuses primarily on frontend design and user interface development rather than executing Python programs.

✨ Features
1. Overview
Welcome page for the development workspace.
Quick-access navigation.
Feature overview using information cards.
2. Code Editor
Text area for writing Python code.
Run and clear buttons.
Dedicated output display section.
3. Variable Explorer
Input fields for variable names and values.
Variable type selection.
Dedicated variable information section.
4. Function Workspace
Function name input.
Parameter input.
Code editor area for function definitions.
5. Loop Playground
For Loop and While Loop selection.
Iteration slider.
Code input area for experimenting with loops.
6. API Testing Interface
API endpoint input.
HTTP method selection.
Request headers input.
Request body input.
Response display section.
7. Console
Command input field.
Execute button.
Console output display area.
8. Customization
Sidebar navigation.
Light and dark theme selection.
Adjustable font size.
Custom CSS styling.

⚙️ Installation and Setup
Step 1: Install Python
Download and install Python from:

https://www.python.org/downloads/

Step 2: Clone the Repository
git clone <your-repository-url>
Step 3: Navigate to the Project Folder
cd DevStudio
Step 4: Install Dependencies
pip install -r requirements.txt
Step 5: Run the Application
streamlit run app.py
The application will open in your default web browser.

📦 Requirements
Create a requirements.txt file containing:

⚠️ Current Limitations
This version is primarily a frontend prototype.

The interface elements, buttons and input fields are implemented, but the following features are not yet connected to backend functionality:

Python code execution.
Variable creation and management.
Function execution.
Loop execution.
Live API requests.
Dynamic console output.
👨💻 Conclusion
DevStudio demonstrates how Python and Streamlit can be used to create an interactive development workspace.

The project provides a foundation for developing a more comprehensive Python playground by combining frontend design with future backend functionality.
